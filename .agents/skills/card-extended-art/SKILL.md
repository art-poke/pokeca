# 카드 확장 아트

중간 승인 없이 분석부터 출력까지 진행한다. 최종 결과는 원본 카드가 가운데 들어간 **슬리브 PNG 1장과 탑로더 PNG 1장**이다.

## 생성 전 분석

1. 첨부 이미지 또는 세트·번호·언어판을 확인한다. 인쇄용 중앙 합성에 쓸 원본과 생성용 참고 이미지를 따로 보관한다. 사용자가 글자를 정리한 참고본을 제공했다면 그것을 사용한다. 원본이 따로 없다면 제공한 카드 이미지를 중앙에 합성한다.
2. 포켓몬과 트레이너의 유무, 위치, 앞뒤·상하 관계, 자세와 카드 밖으로 잘린 윤곽을 기록한다. 카드 글자와 아이콘이 편집에 영향을 주면 imagegen으로 작업용 그림을 정리한다. 인물과 배경은 함께 보존한다.
3. 글자와 테두리를 피해 실제 일러스트에서 주요 팔레트의 HEX를 샘플링한다. 어두운 바탕, 중간색, 광원별 밝은색을 뽑고 각각의 위치와 면적을 함께 적는다.
4. 주요 도로·건물의 화면상 각도(수평 기준), 깊어지는 방향과 소실점, 가까운 곳과 먼 곳의 건물·창문·도로 폭을 카드 폭 대비 비율로 기록한다. 카메라 방향 및 거리는 장면에서 근거를 찾아 추정하고, 측정한 화면 각도와 구분한다.
5. 일러스트가 카드 테두리에 닿는 네 변에서 연결 요소를 하나씩 표에 기록한다. 도로는 차도마다 식별하고 변 이름·변을 따라 잰 교차 위치(%)·중심선 각도·양쪽 경계 위치와 폭·조명색과 밝기를 적는다. 교차로는 연결된 도로와 분기 방향도 표시한다. 테두리나 글자에 가려진 지점은 보이는 구간의 선을 연장해 추정으로 표시한다. 포켓몬이나 트레이너가 잘렸다면 윤곽과 움직임을 이어야 할 방향도 포함한다.
6. 원근은 경계에 가까운 물체를 기준으로 맞춘다. 도시라면 변마다 옥상 한 동의 폭, 창문 간격, 블록 사이 간격의 범위를 카드 폭 대비 비율로 적고 인접 칸의 목표 크기로 사용한다. 도로 폭은 중심선에 직각으로 차도 양끝을 재고, 조명 번짐의 폭은 따로 기록한다. 가려진 수치는 주변에서 보이는 구간으로 범위를 추정한다.

## 하프 일러스트

- 포켓몬이 그려진 그림 창을 생성용 기준으로 잡고, 원본 카드 전체를 인쇄 합성에 사용한다. 그림 창이 카드 위쪽에 있다면 바깥 장면도 그 높이를 기준으로 연결한다.
- 평면 장식 배경은 별·반짝임·기하 패턴의 크기, 밀도, 색과 결을 맞춘다. 피카츄 SC 007/020처럼 그림 창과 하단 카드색이 다르면 위·좌우는 그림 창의 팔레트를 펼치고 아래에는 하단 색을 은은한 빛으로 연결할 수 있다.

## 바깥 8칸 설계

- 생성 전에 3×3 배치로 바깥 8칸의 역할을 각각 적는다. 각 칸에 어떤 지형·건물·인물·광원이 들어갈지, 어디에 시선이 머물고 어디를 조용하게 둘지 원본의 구도와 깊이를 근거로 정한다. 사진형이면 거리·조명·피사체 크기, 일러스트면 형태·필치도 맞춘다.
- 카드와 만나는 변뿐 아니라 바깥 칸끼리 만나는 변에도 같은 길·윤곽·광원이 통과할 위치와 진행 방향을 정한다. 도로처럼 여러 칸을 지나가는 요소는 전체 캔버스에서 먼저 한 줄로 설계한다. 8칸 계획을 한 장의 연속 배경으로 생성한다.
- 두 인쇄 비율과 경계 정렬에 필요한 바깥 여유를 생성 단계에서 확보한다. 좌표 보정으로 이미지 범위 밖이 필요해지면 구도를 조정하거나 해당 영역의 장면을 새로 생성한다. 거울 반사, 타일 반복, 가장자리 픽셀 늘리기로 채우면 선이 꺾이고 피사체가 복제된다.
- 중앙 합성뿐 아니라 바깥 8칸 전체와 칸 사이 경계를 각각 검수한다. 주요 선이 장면의 이유 없이 꺾이는 곳, 대칭으로 복제된 피사체, 갑작스러운 크기 변화가 있으면 해당 구역부터 다시 맞춘다.

## 배경 확장과 검수

- 내장 imagegen을 사용한다. 분석에서 얻은 색상값, 화면 좌표, 각도, 상대 치수를 프롬프트에 전달한다. 카드가 중앙에 놓이도록 기준을 잡고, 주변 8칸을 가로지르는 연속된 그림 한 장을 만든다. 잘린 캐릭터는 기존 자세와 윤곽을 이어 그린다. 카드 UI, 격자와 재단선은 후처리한다.
- 카드 편집을 실행할 수 없으면 카드에 맞춘 바깥 환경을 별도로 생성해 원본 카드와 합성하는 시안을 만들 수 있다. 어떤 방식으로 제작했는지, 경계가 어긋나는 곳이 있는지 최종 결과에 밝힌다.
- 합성에 쓰는 실제 카드 위치를 기준으로 연결 지점을 전체 캔버스 좌표에 옮긴다. 규격별 크롭 후에도 같은 지점을 확인한다. 필요하면 검수용 미리보기에 도로의 중심선과 양쪽 경계를 덧그려 위치·각도·폭을 비교한다.
- 카드 네 변을 확대해 표의 각 도로를 대응시킨다. 비슷한 도로가 근처에 있어도 중심선이나 양쪽 경계가 어긋나거나, 중간에 다른 교차로로 이어지면 그 구간을 다시 맞춘다. 뮤츠 야경에서는 좌측 하단, 중앙 하단, 우측 중앙의 도로를 각각 확인한다. 전체를 축소해 조명과 원근을 보고, 경계가 남은 결과는 시안으로 표기한다.
- 각 규격의 실제 카드 합성본에서 도로가 카드 안팎으로 넘어갈 때 중심선과 차도 양끝을 같은 배율로 비교한다. 이어지는 곳에서 차도가 갑자기 넓어지거나 인접 옥상·창문이 커지면 해당 구역의 규모를 다시 잡는다. 폭과 물체 크기의 변화는 장면의 깊이 변화, 교차로, 차선 합류처럼 원본에서 읽을 수 있는 근거에 따라 완만하게 이어간다.

## 인쇄용 PNG 두 장

- [레포 규격](../../../lib/formats.ts)을 기준으로 3×3을 구성한다. 현재 슬리브는 한 칸 68×92 mm, 전체 204×276 mm다. 탑로더는 한 칸 82×105 mm, 전체 246×315 mm다.
- 동일한 연속 배경을 각 규격에 비율을 유지해 맞춘다. 원본 카드 이미지를 실물 크기 기준(표준 카드는 약 63×88 mm)으로 비율을 유지해 중앙에 합성한다. **카드와 중앙 칸 경계 사이에도 배경 그림이 연속해서 보여야 한다.**
- 이미지 생성 단계와 분리해서 정확한 좌표에 3×3 재단선을 합성하고 인쇄 해상도 메타데이터를 넣는다. PNG를 다시 열어 9칸의 균등 배치, 중앙의 원본 카드, 두 규격의 치수를 확인한다.
- 웹 보기를 요청받았거나 작업 중인 미리보기 페이지가 있다면 두 PNG를 전환해 크게 볼 수 있게 하고, 각각 원본 PNG 다운로드를 제공한다.
