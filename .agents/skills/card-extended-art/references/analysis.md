# 분석 JSON

작업 폴더의 `analysis.json`은 현재 제작할 **그 카드**의 관찰 기록이다. 추정에는 근거와 불확실성을 붙인다. 아래 필드에 실제 관찰값을 채운다. [루기아 기록](cases/lugia.json)은 측정 색과 육안 경계가 함께 있는 사례다.

| 필드 | 기록할 내용 |
| --- | --- |
| source, format | 첨부 또는 SNKRDUNK, 파일·출처·언어·세트·번호·카드명, 요청 규격. 다른 언어의 확장 예시는 reference로만 연결한다. |
| geometry | 입력 px, 입력 안의 카드 외곽 사각형, 카드 안의 일러스트 영역과 헤더·문구·프레임 등 가림 구간, 필드명은 각각 input_px, card_in_input_px, art_in_card_px를 쓴다. 카드 외곽 좌표는 원본 캡처 기준이고 그림 창 좌표는 자른 카드의 왼쪽 위 기준이다. 출력별 사각형은 생성 단계의 layout.json에 기록한다. 사각형은 [왼쪽, 위, 폭, 높이]이며 좌표계와 단위를 명시한다. |
| card_type, cast_type | 인쇄상 포켓몬/트레이너스 등과 실제 장면의 포켓몬/트레이너/둘 다를 각각 적는다. 캐릭터 모양 디저트·문양·장식은 소품으로 기록한다. |
| camera | 첫 시각 분석이다. 카메라가 누구 앞·옆·뒤, 어느 높이에 있고 어디를 향하는지 적는다. 피사체의 시선은 별개다. 전경·중경·후경, 화면 기울기, 지평선·소실 방향의 단서, 거리·단축을 가늠한 근거를 적는다. 관측 가능한 2D 각도와 추정한 3D 자세를 구별한다. |
| subjects, props | 주연·조연·작은 배경 등장 개체까지 ID를 준다. 각각 이름·종류·식별 근거·확신도·화면 위치·보이는 경계 상자·높이와 깊이·자세·시선·가림 순서·잘린 부위를 적는다. 불분명하면 눈에 보이는 특징과 이름 후보를 남긴다. 소품에는 누가 들거나 메었는지, 어느 쪽 어깨에서 어디까지 이어지는지 적는다. |
| palette, light | 둘째로 실제 일러스트의 그림자·중간색·광원·재질별 HEX를 샘플링한다. 원본 px 좌표, 샘플 범위, 대표 영역의 위치와 대략적 점유 범위, 주변 색과 밝기 변화, 빛의 방향을 적는다. 텍스트·프레임·워터마크·홀로그램 반사에 걸린 샘플은 미술색으로 쓰지 않는다. 선 굵기, 명암 경계, 종이결·칠 방향도 맞춘다. |
| edges | 셋째로 top/right/bottom/left 각각의 **모든 의미 있는 교차**를 순서대로 기록한다. 같은 변의 두 날개 끝, 도로 두 개, 머리카락과 가방은 각각 별도 ID다. 통과하는 주체가 없는 변도 무엇이 이어지는지 적는다. |
| layout | 실제 출력 범위에서 필수 연결선의 경로·종점·외부 가림 순서, 각 구역의 역할, 새로 창작하는 부분을 카드 기준으로 계획한다. 규격별 픽셀 변환은 합성 가이드에서 수행한다. 하프 일러스트는 위쪽 그림 창의 높이를 기준으로 놓고, 평면 장식 배경은 무늬 크기·간격·방향을 맞춘다. |

## 경계 한 항목

장면 전체를 지배하는 관계는 별도 `spatial_constraints` 배열에 적는다. 각 항목의 `id`는 생성 지시·결과 판정에서 그대로 쓰고, `source_evidence`에는 측정 근거와 불확실성을, `target`에는 확장된 장면에서 확인할 관계를 적는다. [투시와 비례의 판독 방법](../../card-art-analysis/references/perspective.md)

변의 위치는 실제 그림 영역을 기준으로 좌우 변은 위→아래, 상하 변은 왼쪽→오른쪽 0–100%다. 원본에서 마지막으로 확인되는 두 윤곽점, 변을 건너는 구간, 바깥쪽으로 향하는 접선·두께·곡률과 색을 적는다. 접선은 화면 오른쪽 0°, 아래 90°다. 윤곽이 UI 밑으로 들어가면 마지막 관찰점과 추정한 출구를 구분한다. 인접한 칸에 보일 길이와 자연스러운 종점도 제시한다.

- 손·발·꼬리가 잘리면 각 부위의 주인, 마지막으로 보이는 관절이나 몸통, 경계의 두 윤곽, 바깥에서 닫히거나 가려지는 끝을 한 경로로 기록한다. 같은 손에서 겹친 손가락은 보이는 끝과 사이의 홈을 각각 추적한다. 비교 사진의 카드 테두리와 사진 자체의 바깥 경계도 따로 표시한다. [로켓단의 뮤츠 ex 사례](cases/rocket-mewtwo.json)
- 신체는 머리 폭, 어깨 폭, 몸통 축, 마지막 관절, 단축된 길이를 원본에서 잰다. 너비가 변하는 속도와 겹침을 따라 날개 깃·다리·머리카락을 완성한다. 보이는 끝이 카드 안에서 닫힌 부위는 그 자리에서 끝난다. 프레임 밖, 소품 뒤에 가려짐, 텍스트에 가려짐은 서로 다른 상태다.
- 도로는 중심선·양끝·직각 폭·광원 번짐을 구분해 각각 기록한다. 교차로에는 연결된 도로 ID와 분기 방향을 준다. 옥상 폭·창문 간격·블록 간격을 같은 깊이의 카드 폭 대비 비율로 잰다. 계단에서는 단 코·디딤판·수직면, 가구에서는 상판 타원·다리·수평선처럼 축이 다른 요소를 나눠 본다.
- 지형·수면·무늬는 산등성이·수로의 양안·물보라·반복 무늬가 만나는 높이와 폭을 적는다. 국소 색이 맞아도 폭포의 낙차, 발의 접지점, 침대 높이가 바뀌면 공간이 끊어진다.
