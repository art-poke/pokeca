# 확장아트 결과 검수

원본 카드, `analysis.json`, 이번 회차의 실제 결과 PNG를 열어 판정한다. `layout.json`의 규격별 좌표로 확인할 지점을 찾는다. 기존 시안에 가이드가 없으면 실제 출력에서 카드 외곽을 찾아 원본을 같은 배율로 맞춘다.

제작 완료를 판정할 때는 아래 세 항목을 모두 본다. “손과 발만 봐줘”처럼 범위가 지정된 검수는 요청에 해당하는 ID와 인접 윤곽을 확인하고 `partial`로 기록한다. 전체 제작 통과 판정에는 전체 검수가 필요하다.

1. **전체 장면.** 축소해서 카메라 높이, 인물 간 거리, 피사체 수와 크기, 지면, 광원과 필치가 한 장면으로 읽히는지 본다. 배경에 같은 포켓몬이 하나 더 생겼거나 도로의 소실 방향이 달라졌다면 해당 규격의 전체 판정에 적는다.
   전체 구도 목표가 지정된 경우 목표·생성 전 가이드·최종 PNG를 같은 카드 크기로 대조한다. 주된 물체의 끝, 같은 단면에서 가리는 폭, 뒤에 드러나는 면이 어디서 처음 달라졌는지 기록한다. 가이드 자체가 목표에서 벗어났으면 이를 충실히 따른 결과도 구도 수정 대상으로 판정한다.
   원본의 비교 치수를 같은 배율로 환산하고, 확장 영역에서 새로 보이는 문 전체·벽 높이·바닥 간격 등 독립적인 단서와 대조한다. `spatial_constraints`별로 실제 출력에서 본 위치와 판단을 `spatial_checks`에 남긴다. 평면적인 그림에서는 실제로 쓰인 겹침과 반복 크기를 대조한다.
   문·창이 있으면 전경부터 열린 틈 너머까지 실제 합성본을 따라간다. 가디 9포켓에서는 8→5번의 바닥·문턱·앞발, 5→2번의 틈 안쪽 실내, 5→6·8번의 문짝 자유단과 끝을 본다. 새로 그린 빛이나 러그는 어느 면에 놓였고 어느 물체에 가려지는지 확인한다. 다른 언어판의 철물이나 포켓 띠 뒤가 불분명하면 그 부위의 정합성은 유보한다. [네 샘플 비교판](../card-extended-art/references/cases/growlithe.webp)
   빛이 주요 단서면 최종 규격에서 광원 쪽부터 빛이 통과한 틈, 바닥의 밝은 면, 가림 물체 뒤 그늘까지 추적한다. 같은 깊이의 같은 재질 두 지점에서 명암·색온도를 비교하고, 그림자 경계가 가림 물체의 모서리와 바닥 기울기로 설명되는지 본다. 해당 공간 ID의 `observed`에 확인한 위치를 쓴다. [가디 선호 샘플 실물 사진](../card-extended-art/references/originals/growlithe-light-reference.png)
   부분 보정 전후의 마스터를 같은 배율로 겹쳐 본다. 한 평면의 직선 창살 그림자와 빛 경계는 양 끝을 이은 선에 중간 지점을 대조하고, 부드러운 그림자는 같은 농도의 경계나 띠의 중심을 따라간다. 곧은 벽의 걸레받이 상하단, 바닥의 두 방향 줄눈도 보정 영역 양옆까지 추적한다. 원본 필치·선 굵기·가림을 감안해 새로 생긴 굴곡의 위치를 해당 공간 기준의 `observed`에 기록한다. 공통 마스터에서 발견한 결함은 해당 규격별 최종 PNG에서도 위치와 가시 여부를 확인한다.
2. **네 변 확대.** 각 경계 ID에서 프레임 안 마지막 가시점과 바깥 첫 가시점을 찾아 같은 배율로 비교한다. 통과 위치, 두 윤곽의 진행 방향·두께, 색·명암, 겹침 순서와 끝 모양을 본다. 손가락 사이 홈, 날개 돌기 개수, 가방끈과 몸체, 계단 단 코처럼 색만 맞춰도 놓치는 형상을 확인한다. 보이는 구간의 정합성과 가려진 구간의 불확실성을 분리한다.
   길게 이어진 물체는 카드 안, 경계 직후, 다음 칸 안쪽의 먼 모서리 또는 가림점까지 한 화면에 놓는다. 9포켓은 왼쪽 위 1번부터 행 방향으로 세어 중앙 5번과 해당 이웃 칸을 함께 확인한다. 문의 경우 고정된 손잡이와 문 아랫끝의 간격을 가이드·문턱과 대조한다. 옆면의 두 윤곽을 은테 안팎에서 각각 따라가며 예상 폭과 실제 폭을 비교한다. 옆면이 반사광 한 줄로 사라지거나 전체 축척·투영이 깨지면, 경계 접점이 맞더라도 해당 기준을 `repair`, 해당 규격을 `draft`로 기록한다.
   난간·계단처럼 여러 평행 요소가 이어지면 직선 여부와 함께 카드 경계에서 가로대별 시작 높이, 가로대 사이 간격, 발판 두께를 확인한다. 배경 화면이나 포스터에 생물·인물이 생기면 원본 또는 의도한 연출과 대조해 식별할 수 없는 형상도 검토한다.
3. **인쇄 상태.** 9포켓은 슬리브·탑로더 각각의 실제 재단선과 여덟 칸 연결을 확인한다. PSA·BRG는 투명 창이 있는 인쇄 PNG와 원본을 얹은 장착 미리보기를 함께 열어 창 주변을 확인한다. [출력 규격](../card-extended-art/references/output.md)과 파일 치수·해상도를 대조한다.

이번 회차 폴더의 `review.json`에 [검수 기록 형식](review-format.md)으로 규격별 판정과 재확인 위치를 남긴다. 시안이면 문제가 생긴 ID를 원본 → 분석 → 실제로 보낸 `prompt.md` → 생성본 → 합성본 순서로 대조한다. 원본을 잘못 읽었다면 [분석](../card-art-analysis/SKILL.md)을 고친다. 정확히 관찰한 내용이 명령에서 빠지거나 뒤집혔다면 해당 문장을 고치고, 올바르게 지시했는데 그림에서 틀렸다면 해당 형상과 인접 면을 다시 그린다. 생성본에서는 맞고 합성본에서 밀렸다면 [배치와 합성](../card-extended-art/SKILL.md)을 바로잡는다. 기록이 없는 이전 회차는 확인 가능한 자료에서 판단한다. 재합성 후 고친 경계와 영향을 받은 모든 규격을 새 PNG에서 다시 본다. 검수만 요청한 경우에는 판정과 수정 지시를 전달한다.
