# 오늘의 카드조각

## 두 게임

사이드바의 게임 메뉴에서 포켓몬 카드 보고 이름 맞히기, 다른 포켓몬을 찾아라, 몬스터볼 게임을 고를 수 있다. 선택 화면에서 세 게임의 큰 썸네일을 보여준다. 카드 게임은 같은 날짜에 모두 같은 순서의 문제를 풀며, 첫 오답이 나오기 전까지 계속 이어진다. 각 게임의 응답, 월별 순위, 개인 최고기록은 독립적으로 집계한다.

카드 게임의 첫 화면에서 ‘게임 시작하기’를 누르면 3·2·1 카운트다운 뒤 문제와 타이머가 열린다. 데스크톱에서는 최고기록과 월간 랭킹을 오른쪽에 배치하고, 모바일에서는 게임 아래의 ‘기록과 랭킹’에서 펼쳐볼 수 있다.

### 포켓몬 카드 보고 이름 맞히기

카드의 일러스트 조각을 보고 이름을 입력한다. 정답은 포켓몬 이름이다. 후보 자동완성 없이 한 번 제출한다. 최초 3배에서 시작하며 제출 전에 힌트를 요청하면 2배로 넓어진다.

입력은 유니코드 정규화와 공백 정리를 거쳐 포켓몬 이름과 검수된 별칭에 대조한다. 카드의 포켓몬이 피카츄라면 ‘피카츄 ex’ 카드도 기본 정답은 ‘피카츄’다. 정답이나 마지막 제출 후에는 전체 카드와 카드 상세 링크를 보여준다. 첫 제출에 힌트 없이 맞히면 별 하나를 기록한다.

### 다른 포켓몬 찾기

서로 다른 카드 세 장을 사용한다. 카드에 적힌 메인 포켓몬을 기준으로 두 장은 같은 포켓몬이고 나머지 한 장은 다른 포켓몬이다. 카메오 문제에서는 다른 포켓몬의 카드에 앞선 두 장의 주인공이 작게 그려진다. 결과 화면에서 카드 이름과 카메오를 함께 설명한다.

플레이어가 세 조각 중 하나를 누르면 즉시 답을 제출한다. 얼굴 전체 대신 귀, 꼬리, 몸의 무늬처럼 구분할 단서가 있는 부분을 카드마다 골라 3배로 확대한다. 채점 후 세 카드가 차례로 펼쳐지고, 같은 포켓몬 두 장과 정답 카드를 각각 표시한다.

각 문제의 제한 시간은 20초이며, 힌트를 보거나 새로고침해도 서버의 시작 시각을 기준으로 이어진다. 오답과 시간 초과에는 X 연출과 정답 카드가 표시되고 게임이 끝난다. 정답이면 색종이 효과와 3초 카운트다운을 보여주고 다음 문제로 넘어간다. 전체 진행 시간은 문제 사이에 이어지고 종료되면 멈춘다. 하루 한 번의 랭킹 도전이 끝나면 ‘새 게임 시작’으로 연습 게임을 제한 없이 시작할 수 있다. 연습 기록은 랭킹 기록에 합산하지 않는다.

## 확대 영역과 원본

- 카드별로 일러스트 영역을 원본 이미지 기준 정규화 좌표로 기록한다. 하프 일러스트에는 실제 그림 창만 포함한다. 풀 일러스트는 글자가 겹치는 부분을 고려해 정답이나 카드 식별 정보가 보이지 않는 프레임만 허용한다.
- 확대율은 일러스트 전체가 보이는 크기를 1배로 정의한다. 3배에서는 영역 너비와 높이의 각각 1/3이 보인다. 원본 비율을 유지하고, 화면에 맞출 때 조각의 내용이 추가로 잘리지 않게 한다.
- 이름 맞히기는 검수된 기준점에서 좌상·우상·좌하·우하 방향으로 이동한 조각을 만든다. 그림 가장자리에서 같은 조각이 만들어지면 하나만 저장한다. 랭킹은 날짜별 위치를 고정하고, 연습에서는 저장된 위치 중 하나를 뽑는다. 힌트는 고른 중심점에서 넓어지며 모든 프레임은 그림 영역 안에 들어간다.
- 기존 SNKRDUNK 수집 스크립트의 카드 식별과 이미지 다운로드 로직을 참고한다. 현행 수집은 목록 이미지에서 시작하고 URL에 질의가 없을 때 `size=l`을 붙인다. 파일 크기와 픽셀 치수를 확인하고 카드 상세에서 제공하는 해상도와 비교한 뒤 출제에 사용할 원본을 결정한다.
- 출제에 쓰는 원본과 퀴즈용 조각을 각각 보관한다. 플레이 중에는 정답, 카드 ID, 원본 URL, 미공개 힌트 없이 현재 단계의 조각만 내려준다. 조각 파일 이름과 메타데이터에도 카드 이름을 넣지 않는다. 제출 이후 서버가 채점하고, 문제가 끝나면 전체 카드 정보를 반환한다.

## 기록과 연출

- 로그인 계정별로 제출 결과를 저장한다. 다시 접속하면 남은 시도와 현재 조각부터 이어가며, 완료 결과는 다시 열어볼 수 있다. 새로고침과 중복 제출이 시도 수나 기록을 늘리지 않도록 서버에 저장된 문제 진행 상태를 기준으로 채점한다.
- 이름 맞히기 힌트는 한 판에 두 번까지 쓸 수 있다. 일일 랭킹은 당일 한 판의 사용 기록을 합산하고, 연습은 새 연습판을 시작할 때 두 번으로 초기화한다.
- 이름 맞히기 월간 순위는 별 개수, 전체 정답 수 순으로 계산한다. 개인 최고기록은 한 달 최다 별과 최장 연속 첫 답 정답이다. 다른 포켓몬 찾기는 월간 정답 수와 최장 연속 정답을 기록한다. 두 게임 모두 이전 달 순위를 볼 수 있고, 동점은 공동 순위로 표시한다. 연속 기록은 한국 시간 기준 연속 날짜로 계산한다.
- 이름 맞히기는 조각이 넓어질 때 셔터음, 정답 공개 때 짧은 상승음을 사용한다. 다른 포켓몬 찾기는 카드 세 장의 공개 타이밍에 맞춰 가볍게 넘기는 소리를 낸다. 기본 무음과 스피커 토글을 제공하며, 동작 줄이기 설정에서는 확대와 뒤집기 효과 없이 결과를 표시한다.

## 첫 출제 후보

| 문제 | 카드 후보 | 확인할 항목 |
| --- | --- | --- |
| 이름 맞히기 | 피카츄 `SV2a 173/165` | 풀 일러스트 후보. 3배에서 알아볼 단서와 글자 노출 여부를 확인한다. |
| 이름 맞히기 | 리오르 `SVI 031/066` | 원본에서 카드 그림 창의 경계를 확인했다. |
| 다른 포켓몬 찾기 | 피카츄 `SV2a 173/165`, 피카츄 ex `SV8 132/106`, 이브이 `SV5a 078/066` | 세 조각에서 종류를 구분할 단서가 보이는지 확인한다. |

시작 세트는 피카츄 두 장을 SNKRDUNK 상세 이미지에서, 리오르와 이브이를 공식 한국 카드 사이트에서 가져온다. 처음 하프 일러스트 후보였던 이브이 MC 카드는 원본 화면에서 풀 일러스트로 확인됐다. 같은 날 두 게임에 원본 카드를 중복 출제하지 않는다.

## 모바일 화면

- 이름 게임의 이미지와 입력을 한 열로 배치하고 제출 버튼을 입력 옆에 둔다. 입력은 16px, 주요 버튼은 최소 48px 높이로 유지한다.
- 찾기 게임은 좁은 화면에서도 세 조각이 한 줄에 나오게 한다. 조각 전체를 눌러 답을 제출한다. 결과는 색과 함께 텍스트로 표시한다.
- 두 게임 모두 모바일에서는 게임 아래에 개인 기록과 월간 순위를 배치한다.

## 첫 세트 발행

1. `npm run db:migrate`로 대상 DB에 스키마를 적용한다.
2. `node --env-file-if-exists=.env.local scripts/publish-card-fragments.mts data/card-fragments-starter.json YYYY-MM-DD --preview /tmp/card-fragments-preview`로 조각과 전체 카드를 검수한다.
3. 같은 명령에서 `--preview /tmp/card-fragments-preview`를 빼고 실행하면 지정 날짜의 두 문제가 트랜잭션으로 발행된다. 기존 발행 날짜는 덮어쓰지 않는다.

일자별 목록을 발행하면 한국 시간 자정부터 서비스에 나타난다. 해당 날짜에 발행된 문제가 없으면 준비된 문제가 없다는 안내를 표시한다.

11월 22일 시작 세트는 `data/card-fragments-starter.json`, 11월 23~26일의 첫 문제는 날짜별 목록을 사용한다. 이외 첫 문제와 각 날짜 두 번째·세 번째 문제는 `data/card-fragments/season-01.json`에 있다. 11월 22일~1월 15일에 배치한 검수 문제 330개는 세 문제 이후에도 재사용한다. 각 날짜와 게임에 고정된 순서로 이어지며, 전체 문제를 돌면 순서를 섞어 계속한다.

찾기 문제는 피카츄, 리자몽, 뮤츠, 뮤, 이브이, 블래키를 중심으로 구성했다. 카메오 출제에는 예를 들어 피카츄가 등장하는 글레이시아 카드도 사용한다. 이름 맞히기의 첫 문제는 55일 동안 서로 다른 카드 55장을 사용한다. 이미지는 SNKRDUNK 상세와 한국 공식 카드 사이트에서 수집했다.

출제표를 스테이지 단위로 발행하려면 `node --env-file-if-exists=.env.local scripts/publish-card-fragments.mts data/card-fragments/season-01.json --all --stage 2`처럼 스테이지 번호를 지정한다. `--preview /tmp/card-fragments-preview`를 추가하면 DB 없이 카드 조각을 생성한다. 기존 찾기 문제의 조각만 바꾸려면 같은 출제표로 `--refresh-odd-crops`를 지정한다. 발행된 카드 순서와 정답을 확인한 뒤 조각만 갱신한다.

`data/card-fragments/expansion-01.json`은 포켓몬 51종의 추가 이름 문제 은행이다. `node --env-file-if-exists=.env.local scripts/publish-card-fragments.mts data/card-fragments/expansion-01.json --all --bank-only`로 등록하면 기존 일일 문제를 유지한 채 이름 게임의 이어 풀기와 연습에서 사용할 수 있다.

`data/card-fragments/snkrdunk-01.json`은 SNKRDUNK 상세 페이지에서 수집한 일본판 76장과 두 게임의 추가 문제 81개를 함께 관리한다. 아래 명령은 같은 목록으로 카드 검색을 갱신하고 문제 은행을 등록한다. 운영에서 카드 검색 이미지를 제공하려면 수집한 `.cache/snkrdunk-images/` 파일을 기존 이미지 버킷의 `jp-cards/` 경로에 올린다.

```sh
node --env-file-if-exists=.env.local scripts/import-snkrdunk-library.mts data/card-fragments/snkrdunk-01.json
node --env-file-if-exists=.env.local scripts/publish-card-fragments.mts data/card-fragments/snkrdunk-01.json --all --bank-only
```

`data/card-fragments/snkrdunk-02.json`에도 같은 명령을 적용한다. 47종의 카드 60장을 담고 있으며, 이름 맞히기 56개와 다른 포켓몬 찾기 20개를 추가한다. 수집 목록에 한국판과 같은 카드가 있으면 검색은 기존 한국판을 유지한다.

`data/card-fragments/snkrdunk-03.json`은 세대별 포켓몬 51종의 카드 69장이다. 이번 목록의 모든 카드를 두 게임에서 사용하며, 이름 맞히기와 찾기에 각각 69문제를 추가한다. 찾기의 동일 포켓몬 카드 두 장은 서로 다른 판본을 사용한다.

`data/card-fragments/snkrdunk-04.json`은 2세대 도감에서 출제되지 않던 75종의 카드 88장이다. 이름 맞히기와 찾기에 각각 88문제를 더한다. 기존 문제 은행에 있던 25종과 합쳐 두 게임 모두 2세대 도감 152~251번을 다룬다.

`data/card-fragments/odd-expansion-01.json`은 기존 카드로 만든 찾기 전용 문제 100개다. 각 조합은 다른 그림의 동일 포켓몬 카드 두 장과, 기존 찾기에 없던 포켓몬 카드 한 장을 사용한다. `node --env-file-if-exists=.env.local scripts/publish-card-fragments.mts data/card-fragments/odd-expansion-01.json --all --bank-only`로 문제 은행에 등록한다.

연속 랭킹은 해당 날짜에 아직 나오지 않은 카드 조합부터 고른다. 연습은 재시작해도 최근 문제 24개를 기억한다. 카드 번호와 카드 조합을 기준으로 같은 문제를 판별한다. 찾기에서는 기존에 검수한 그림 영역 안에서 더 작은 조각을 보여주고, 결과 화면에서 전체 카드를 공개한다.

두 게임의 조각은 카드 원본 비율과 위치를 기록한다. 답이 공개되면 같은 자리에서 조각의 테두리가 카드 전체까지 넓어진다. 이름 맞히기의 1~3번째 문제는 검수한 그림 중심을 기준으로 1.25배, 4~6번째는 1.7배로 보여준다. 7번째부터는 다양한 위치에서 3배로 확대한다. 힌트는 같은 카드 틀에서 각각 1배, 1.25배, 2배까지 넓힌다. 발행된 문제에 새 조각을 추가할 때는 `node --env-file-if-exists=.env.local scripts/backfill-card-fragment-placement.mts`를 실행한다.

찾기 게임은 랭킹과 연습 모두 연속 정답 수에 따라 조각을 줄인다. 1~2번째 문제는 일러스트 너비와 높이의 약 83%, 3~5번째는 65%, 6~9번째는 48%, 10~14번째는 36%, 15번째부터는 25%를 사용한다. 그림 창이 작은 카드도 해당 카드의 검수된 일러스트 영역을 기준으로 자른다.

## 이로치와 카메오 문제

`data/card-fragments/snkrdunk-05.json`은 SNKRDUNK에서 이번에 확보한 16장과 기존 카드로 구성한 찾기 전용 문제다. 높은 난이도에서는 한 장에 한해 검수한 카메오나 배경 후보 중 하나를 날짜와 판본으로 정한다. 답을 공개하면 카드별로 확인된 이로치와 카메오를 표시한다.

| 유형 | 카드와 단서 | 문제 구성 |
